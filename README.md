# Python Sales Management System

## Project Overview
This is a simple Sales Management System developed using Python. It helps manage products, monitor stock levels, record sales transactions and calculate total revenue.

## Features
- View available products.
- Add new products.
- Record sales.
- Automatically calculate total sales.
- Update product stock after sales.
- Generate a sales summary.
- Calculate total revenue.

## Technologies Used
- Python 3
- Dictionaries
- Lists
- Functions
- Loops
- Conditional statements
- User input and output

## How to Run the Project

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
py sales_management_system.py
```

This project was developed as part of my Python programming practice to apply fundamental programming concepts in building a practical sales management application.
